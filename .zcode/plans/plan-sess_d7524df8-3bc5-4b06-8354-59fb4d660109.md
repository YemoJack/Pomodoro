# 计时配置与轮次逻辑优化计划

## 目标

把当前的“长休息周期”模型调整为用户确认的“固定总轮数”模型：

- 一轮 = 一次专注 + 一次休息（最后一轮只有专注，不安排休息）。
- 可在主计时页面快捷编辑专注时间、休息时间和总轮数。
- 跳过专注会推进轮次并进入本轮休息，但不会增加“完成番茄”统计。
- 跳过最后一轮专注则直接结束本次计划，不进入休息。
- 跳过休息只进入下一轮专注，不再次推进轮次。

## 现状与根因

当前 `TimerStore` 用 `completedFocusesInCycle` 同时表达“完成番茄数”和“周期位置”。`skipCurrentPhase()` 只记录未完成会话并直接开始短休息，没有推进这个计数，因此：

- 跳过专注后仍显示同一轮数。
- 跳过最后一轮不会结束计划。
- 长休息间隔逻辑与当前需求不一致。

“今日完成番茄数”仍应只统计完整完成的专注阶段，跳过的专注不计入统计。

## 修改范围

### 1. 设置模型与持久化

修改 `Stores/SettingsStore.swift`：

- 增加 `breakMinutes`，用于统一表示休息时长。
- 增加 `totalRounds`，表示本次计划的总专注轮数。
- 默认值：专注 `25` 分钟、休息 `5` 分钟、总轮数 `4`。
- 保留对旧 `settings.shortBreakMinutes` 和旧长休息配置的读取兼容：如果新键不存在，使用旧短休息值作为 `breakMinutes`，旧的长休息间隔可迁移为 `totalRounds`。
- `duration(for:)` 的休息阶段统一使用 `breakMinutes`；不再产生新的长休息阶段。
- 旧的 `longBreakMinutes` / `longBreakInterval` 键不再参与新流程，避免用户继续看到已经废弃的长休息配置。

### 2. 计时状态机

修改 `Stores/TimerStore.swift` 和 `Models/TimerModels.swift`：

- 将周期计数语义调整为“本次计划已经结束的专注轮数”，包含完整完成和跳过，但不代表完成番茄统计。
- 增加/保存当前轮次状态，默认从第 `1 / totalRounds` 轮开始。
- 抽取统一的专注结束处理逻辑，供自然完成和跳过共同调用：
  1. 写入 `FocusSession`，`completed` 按实际情况传入。
  2. 推进轮次位置。
  3. 若已到最后一轮，进入“已完成”状态，不创建休息阶段。
  4. 否则进入当前轮对应的休息阶段。
- `skipCurrentPhase()` 调整为：
  - 跳过专注：记录未完成、推进轮次；非最后一轮开始休息，最后一轮直接结束。
  - 跳过休息：记录未完成休息，直接开始下一轮专注，不推进轮数。
- 自然完成专注使用同一套轮次推进逻辑；自然完成/跳过休息都只负责进入下一轮专注。
- `autoStartBreaks` 和 `autoStartFocus` 继续保留：
  - 非最后一轮专注结束后，按设置决定是立即开始休息还是停在待开始状态。
  - 休息结束后，按设置决定是立即开始下一轮专注还是停在待开始状态。
  - 跳过专注按用户明确要求直接进入本轮休息；跳过最后一轮直接结束。
- 修改 `cycleDescription`，在专注时显示 `第 N / M 轮`，休息时显示刚结束的轮次或“准备下一轮”，避免计数语义混乱。
- 计时快照继续支持旧 `timerSnapshot.v1`：旧字段解码为新的轮次进度；旧的 `.longBreak` 恢复时按普通休息处理，避免已有本地计时状态无法恢复。
- 设置变更时，正在进行的阶段不变；下一阶段使用新时长，总轮数变更只影响后续轮次判断。

### 3. 主页面快捷编辑

新增 `Views/QuickSettingsView.swift`，并调整 `Views/RootView.swift`：

- 在主窗口顶部右侧增加 SF Symbol 设置按钮（使用 `slider.horizontal.3` 或 `gearshape`），打开紧凑 popover。
- 快捷编辑内容只有三项：
  - 专注时间：`1–120` 分钟
  - 休息时间：`1–60` 分钟
  - 专注轮数：`1–12` 轮
- 使用原生 `Stepper` / `LabeledContent`，数字更新即时写入 `SettingsStore`。
- 显示简短提示：“计时中的修改将在下一阶段生效。”
- 主页面快捷编辑与系统设置窗口使用相同的 `SettingsStore`，确保菜单栏、主窗口和设置窗口始终一致。

### 4. 系统设置窗口

调整 `Views/SettingsView.swift`：

- 计时页改为展示专注时间、休息时间、总轮数。
- 移除长休息时长和长休息间隔控件，因为新需求不再使用长休息周期。
- 保留自动化、通知、数据清空等已有设置。
- 将说明文案从“长休息间隔”改成“本次计划总轮数”。

### 5. 菜单栏和显示文案

调整 `Views/MenuBarView.swift`、`Views/TimerView.swift`：

- 菜单栏显示当前轮次，例如 `第 2 / 4 轮`。
- 休息阶段统一显示“休息”，不再显示“短休息/长休息”。
- 最后一轮专注完成或跳过后显示“计划完成”状态，主操作变为“重新开始”，不会再进入休息。
- “完成番茄”统计保持原规则：只有完整专注阶段增加。

### 6. 测试

扩展 `PomodoroTests/TimerStoreTests.swift`：

- 跳过专注后轮次推进，且会话 `completed == false`、今日完成番茄数不增加。
- 跳过非最后一轮专注后进入休息。
- 跳过最后一轮专注后直接进入完成状态，不产生休息。
- 跳过休息后进入下一轮专注，轮次不重复推进。
- 自然完成非最后一轮进入休息，自然完成最后一轮结束计划。
- 设置默认值、范围及 `breakMinutes` / `totalRounds` 持久化。
- 运行现有会话统计测试，确保跳过不影响完成番茄和专注时长统计。

## 验证方式

1. 使用 Xcode 构建 Debug App。
2. 运行完整 XCTest suite。
3. 启动 `.app` 做一次运行冒烟检查。
4. 手动将设置改为短时长和 2 轮，验证：
   - 第 1 轮专注跳过 → 进入休息并显示下一轮。
   - 第 2 轮完成或跳过 → 计划结束，没有额外休息。
   - 统计只增加完整完成的专注。
