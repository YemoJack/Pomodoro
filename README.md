# 番茄专注

一款面向考研复习的原生 macOS 极简番茄钟。主窗口负责计时与今日记录，菜单栏提供随时可用的快捷控制。

## 功能

- 内置标准番茄、短时冲刺、上课模式和深度专注预设
- 支持新建、重命名、修改和删除自定义预设，自动执行选项随预设保存
- 可编辑专注时间、休息时间和本次专注轮数，自定义专注最长 6 小时
- 长按计时圆环并旋转，设置下一次单次专注，最长 3 小时；长按时显示进度反馈
- 可分别开启专注结束自动休息、休息结束自动继续
- 暂停、继续、跳过和提前结束
- 每轮由专注与休息组成，最后一轮专注后直接结束
- 菜单栏剩余时间与快捷操作
- 打开时复用已有主窗口，支持计时窗口置顶
- 阶段完成系统通知与提示音
- 专注结束时在屏幕最上层显示全屏提示，支持点击关闭
- 设置中可开关全屏提示、调整不透明度与持续时间，并即时预览
- 可分别配置普通专注结束、休息结束、最后一轮结束的提示音，均不依赖自动执行开关
- 每类提示音支持独立的系统声音或本地自定义音乐文件；自定义音乐按文件实际长度播放
- 自定义音乐首次选择后会导入 App 专用目录，后续播放无需再次访问原文件
- 数据页展示累计与今日统计，并可滚动查看全部计时记录
- 今日番茄数、专注时间和最近记录
- 睡眠、锁屏或重启后的计时状态恢复
- 本地设置和记录，不依赖账号或网络
- 专注阶段可独立为 App 和 Chrome 网站设置黑名单或白名单，支持单项临时放行 2 分钟

## 开发环境

- macOS 14+
- Xcode 16+
- Swift 6

## 运行

```bash
open Pomodoro.xcodeproj
```

在 Xcode 中选择 `Pomodoro` scheme 后运行。首次开始专注时，App 会说明并请求通知权限。

如果终端当前指向 Command Line Tools，可使用：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project Pomodoro.xcodeproj \
  -scheme Pomodoro \
  -configuration Debug \
  -derivedDataPath .build \
  CODE_SIGNING_ALLOWED=NO build

## 专注限制

在「设置 → 专注限制」中为 App 和网站选择模式、添加名单，再打开「启用专注限制」。名单在每轮开始时生效。暂停或进入休息时解除限制。

计时器底部也可以开关专注限制。在设置中选择「全局限制」后，启用的专注轮次会显示全屏计时器并限制切换到其他 App。计时结束自动恢复。提前结束请点击「强行终止」，并在 macOS 系统对话框中验证登录密码。

### 连接 Chrome

1. 在 Pomodoro 的「设置 → 专注限制」中点击「注册本机连接」。
2. 打开 Chrome 的 `chrome://extensions`，启用「开发者模式」，点击「加载已解压的扩展」并选择项目中的 `ChromeExtension` 文件夹。
3. 打开 Pomodoro 扩展菜单，点击「授权网站访问」。保持 Pomodoro 运行，确认设置显示「Chrome 已连接」。移动 App 或切换构建目录后，重新注册本机连接。

网站限制覆盖启用了扩展的 Chrome 普通窗口。白名单场景请同时加入工作网站和登录时跳转的域名。拦截新导航后，临时放行会重新打开该网站首页。已打开的标签页会在放行时直接移除遮罩。
```
